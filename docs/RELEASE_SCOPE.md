# Privacy and publication scope

The public files contain only this article's questionnaire observations/results and its experimental inputs, coding definitions and analysis code.

The anonymised raw-data export removes names, original respondent IDs, school identifiers, class and grade, demographic variables, IP addresses, submission timestamps, completion duration, platform/source fields, open-ended responses and unrelated items. Each form is independently shuffled with an unpublished random permutation and receives new release-only identifiers. No source-to-release key is retained. The retained original numeric response vectors, marginal counts and all seven joint distributions are unchanged.

Full survey-platform Excel exports and filled questionnaires are excluded. Blank questionnaire text is exported from the instruments without DOCX comments, author properties or embedded metadata.

The public snapshot excludes generated AI response texts, human coding observations attached to those responses, classifier predictions/checkpoints, model-output samples, AI-derived statistical results, manuscript files and manuscript result figures. Prompt/scenario inputs and methods are included. Analysis outputs are ignored by Git.

This scope describes the current publication snapshot. Earlier Git commits or previously published release assets are not rewritten by this update.
